# 🍔 Food Delivery Cost and Profitability Analysis

## 📌 Project Overview
This project analyzes the cost, revenue, and profitability of a food delivery business using Python and data analytics. The main objective is to understand the profit and loss per order and identify ways to improve business profitability.

## 🎯 Objectives
- Analyze food delivery order data.
- Calculate revenue, total costs, and profit.
- Understand the impact of discounts and delivery charges.
- Visualize cost breakdown and profit distribution.
- Compare actual profitability with recommended commission and discount strategies.

## 📊 Dataset
The project uses the `food_orders_new_delhi.csv` dataset, which contains food delivery order information.

The dataset includes information such as:
- Order Value
- Commission Fee
- Delivery Fee
- Payment Processing Fee
- Discounts and Offers
- Order Date and Time
- Delivery Date and Time

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Analysis Performed
1. Data loading and preprocessing
2. Date and time conversion
3. Discount extraction and calculation
4. Revenue calculation
5. Total cost calculation
6. Profit calculation per order
7. Profit distribution analysis
8. Cost breakdown visualization
9. Actual vs. recommended profitability comparison

## 💰 Profit Calculation

**Revenue:**
Commission Fee

**Total Costs:**
Delivery Fee + Payment Processing Fee + Discount Amount

**Profit:**
Revenue − Total Costs

## 📈 Visualizations
The project includes the following visualizations:

- Profit Distribution per Order
- Costs Breakdown
- Proportion of Total Costs
- Commission and Discount Analysis
- Actual vs Recommended Profitability

## 💡 Key Insights
- Discounts have a significant impact on profitability.
- Delivery and payment processing costs affect profit margins.
- Commission rates influence overall revenue.
- Optimizing discount and commission strategies can improve profitability.

## 🚀 Recommendations
- Optimize discount offers.
- Review commission rates.
- Reduce unnecessary delivery costs.
- Use data-driven pricing strategies.
- Focus on improving profit per order.

## ▶️ How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Food-delivery-cost-and-profitability.git
   ```

2. Open the project folder in VS Code.

3. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open `analysis.ipynb`.

6. Run all notebook cells to see the analysis and visualizations.
